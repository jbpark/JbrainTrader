## 1. 전체 실행 구조

`run_mo.bat`은 Anaconda Python으로 `export/martingale_mo.py`를 실행하는 런처입니다. 인자로 서버를 선택하며(`hankook`=한국투자증권 KIS 모의 / `kiwoom`=키움 모의, 기본값 hankook), 키움 선택 시 게이트웨이(`run_kiwoom_admin.bat`)를 먼저 띄운 뒤 5초 대기합니다.

**초기화 순서:**

1. **싱글턴 체크** — 127.0.0.1:9877 포트 바인딩으로 중복 실행 차단
2. **인증 정보 로드** — `.env`의 API 키를 `secret.key`(Fernet)로 복호화. 없으면 `backend/settings/account_config.json`에서 보조 로드 → 브로커 인증 (실패 시 즉시 종료)
3. **전략 로드 & 컴파일** — `StrategyManager`가 `strategy/COMPLEX_MARTINGALE_PYRAMID.txt`(INI 형식)를 읽고, `TradingStrategy`가 각 condition 문자열을 Python 코드 객체로 사전 컴파일(`compile(..., 'eval')`)하여 매 분 고속 평가
4. **지표 웜업** — Yahoo에서 최근 7일 1분봉을 받아 최근 200봉을 엔진에 순차 주입 (EMA20/60, MACD, ATR, VWAP, RSI, 볼린저밴드 계산 준비)
5. **잔고 동기화** — 브로커 잔고 조회 후 069500 보유분이 있으면 내부 포지션 복원 (§7-1 수정 반영: 상태 파일 기반 랏 구조 복원)
6. **메인 루프** — 장중(09:00~15:40) 매 분 2초 시점에 1분봉 갱신 → 매수 신호 우선 판정 → 없으면 매도 신호 판정 → 주문 실행 → 리포트(`report/YYYYMMDD_mo_..._report.md`) 기록

### 메인 루프 세부 동작

- **시간 게이트**: 09:00~15:40 외에는 30초 간격 대기 (요일/공휴일 체크는 없음)
- **동기화 슬립**: `62 - 현재초`만큼 대기 → 항상 매 분 **+2초** 시점에 판단 실행
- **데이터 갱신**: 최근 1일치 1분봉을 다시 받아 마지막 행만 사용. 직전과 timestamp가 같으면 스킵(중복 차단), 히스토리는 200봉 롤링 유지
- **신호 우선순위**: 매수 신호가 있으면 매수만 실행(매도 판정 생략) → 매수 없을 때만 매도 판정 (STOP_LOSS → TIME_STOP → SELL_STEP 순)
- **주문**: 현재 봉 종가를 가격으로 지정가 주문. 접수 성공(`rt_cd == "0"`) 시 내부 포지션 갱신 + 리포트 기록. 부분 매도 시 LIFO(최근 매수분부터) 차감
- **예외 처리**: 루프 내 오류는 로깅 후 10초 대기 → 재시도 (프로세스는 죽지 않음)

## 2. 전략 규칙 상세 — 매수 (분할 진입)

전략 엔진은 **보유 랏(lot) 개수 + 1 = 현재 단계(step)** 로 계산하여, 해당 단계의 `BUY_STEP_N` 섹션 조건만 검사합니다. 조건 평가 컨텍스트에는 `price`(현재 종가), `last_buy_price`(마지막 매수가), `avg_price`(평단가), `position_qty`(보유 수량), `highest_price`(진입 후 최고가) 등이 주입됩니다.

| 단계 | 조건 | 매수량 | 의미 |
|------|------|--------|------|
| STEP 1 | `true` (무조건) | 20주 | 최초 진입. 포지션이 비면 **다음 봉에서 즉시 재진입** |
| STEP 2 | 보유 20주 && (마지막 매수가 대비 **+5% 이상** 또는 **−5% 이하**) | 상승: 20주 / 하락: 60주 | 분기점: 상승 시 **불타기 1차**, 하락 시 **물타기 1차** (1:3 배수) |
| STEP 3 | 보유 40주 && +7% (불타기) 또는 보유 80주 && −5% (물타기) | 불: 10주 / 물: 180주 | 불타기 2차(감속: 20→10) / 물타기 2차(1:3:9 → 총 260주) |
| STEP 4 | 보유 50주 && +10% | 5주 | 불타기 3차 (감속 심화). 물타기 상태(260주)는 추가 매수 금지 |
| STEP 5~10 | 보유 55주 이상 260주 미만 && +12% | 각 2주 | 불타기 4차 이후 극소량 피라미딩 (동일 조건 6회 반복 정의) |

> ※ `max_steps = 50`으로 선언되어 있으나 실제 정의된 섹션은 10단계까지이므로 11단계 이상은 동작하지 않습니다. 상승 % 조건은 모두 **마지막 매수가** 기준입니다.

### 매수 경로 분기 구조

**불타기 경로 — 상승 추세 추격 (감속형 피라미딩)**

```
20주 @ P        (진입)
+20주 @ 1.050P  (+5%)   → 40주
+10주 @ 1.124P  (+7%)   → 50주
 +5주 @ 1.236P  (+10%)  → 55주
 +2주 @ 1.384P  (+12%)  → 57주
 ...  (+12%씩, 최대 6회) → 최대 67주
```

추가 매수량이 20→20→10→5→2로 줄고 요구 상승폭은 5→7→10→12%로 커지는 **역마틴게일 감속** 설계. 평단가 상승을 최소화하며 추세에 올라탐.

**물타기 경로 — 하락 시 배수 증액 (마틴게일)**

```
20주 @ P         (진입)
+60주 @ 0.9500P  (−5%)   → 80주
+180주 @ 0.9025P (−5%)   → 260주 (최종)
─────────────────────────
260주 이후 추가 매수 전면 금지
추가 −5% (0.8574P) → 기계적 손절
```

1 : 3 : 9 배수 물타기. 총 260주에서 상한을 두고, 그 이후 하락은 손실을 확정해 **자금 고립을 차단**하는 것이 이 전략의 핵심 아이디어.

## 3. 전략 규칙 상세 — 매도 (청산)

| 규칙 | 조건 | 수량 | 성격 |
|------|------|------|------|
| SELL_STEP_1 (a) | 보유 **80주 미만** (불타기 상태) && 진입 후 최고가가 평단가 +1.5% 이상 도달한 적 있음 && 현재가가 평단가 +1% 이하로 하락 | 전량 | 간이 트레일링 익절 — 수익 절정에서 꺾이면 +1% 부근 확보 후 이탈 |
| SELL_STEP_1 (b) | 보유 **80주 이상** (물타기 상태) && 현재가 ≥ 평단가 +0.5% | 전량 | 본전 탈출 — 반등 시 즉시 원금+α 회수, 고립 기간 최소화 |
| STOP_LOSS | 보유 **260주 이상** && 마지막 매수가 대비 −5% 이하 | 전량 | 물타기 최종 단계 이후의 기계적 손절 (유일한 손절 규칙) |

> **비대칭 청산 구조:** 불타기 쪽은 트레일링으로 이익을 지키고, 물타기 쪽은 이익을 노리지 않고 본전 탈출만 노립니다. 반대로 **손절은 260주 최종 물타기 이후에만 존재**하며, 그 사이(20~80주 구간)의 하락은 물타기 규칙이 흡수하는 구조입니다.

## 4. 수치 시나리오 분석

### 물타기 최악 시나리오 (최초 진입가 P 기준)

| 이벤트 | 체결가 | 매수량 | 누적 수량 | 누적 투입 | 평단가 | 평단 대비 평가손 |
|--------|--------|--------|-----------|-----------|--------|------------------|
| 1차 진입 | 1.0000P | 20 | 20 | 20.00P | 1.0000P | 0% |
| 물타기 1차 (−5%) | 0.9500P | 60 | 80 | 77.00P | 0.9625P | −1.30% |
| 물타기 2차 (−9.75%) | 0.9025P | 180 | 260 | 239.45P | 0.9210P | −2.00% |
| **본전 탈출가** (평단 +0.5%) | **0.9256P** | — | — | 저점(0.9025P) 대비 **+2.56% 반등**이면 전량 청산 (수수료 전 +0.5%) | | |
| **기계적 손절가** (−14.26%) | **0.8574P** | — | — | 회수 222.92P → **손실 −16.53P** (총투입 대비 **−6.90%**, 최초 진입금 20P 대비 **−82.7%**) | | |

> **자금 소요와 손익 비대칭이 이 전략의 본질입니다.**
> 최초 진입금(20P)의 약 **12배(239.45P)** 가 물타기 예비 자금으로 항상 대기해야 합니다. 예를 들어 KODEX 200을 48,000원으로 가정하면 최초 진입 약 96만 원, 최대 투입 약 **1,150만 원**입니다. 반면 회당 이익은 +0.5~1% 수준(십수만 원), 손절 시 손실은 약 −16.5P(약 −79만 원, 최대 투입 대비 −6.9%)로, **"자주 작게 벌고 가끔 크게 잃는"** 전형적 마틴게일 손익 분포를 가집니다. 지수가 약 −14.3% 이상 추세 하락하면 손절이 확정되며, 손절 직후 STEP 1이 즉시 재진입하므로 하락장이 이어지면 이 사이클이 반복됩니다.

### 실전에서의 지배적 패턴: +1% 스캘핑

불타기 1차(+5%)에 도달하려면, 진입 후 최고가가 +1.5%를 찍은 뒤 +1% 이하로 **한 번도 꺾이지 않고** +5%까지 직행해야 합니다(꺾이는 순간 트레일링 익절로 전량 청산). KODEX 200 같은 지수 ETF에서 되돌림 없는 +5% 랠리는 드물기 때문에, 실제 거래의 대부분은 다음 두 갈래로 수렴합니다:

- **+1.5% 도달 → 되돌림 → 약 +1% 익절** (가장 빈번)
- **−5% 도달 → 물타기 → 반등 시 +0.5% 본전 탈출** 또는 드물게 손절

즉 문서상 "불타기 피라미딩"은 정의되어 있으나 발동 빈도는 매우 낮고, 사실상 **물타기 기반 평균회귀 스캘핑**으로 동작한다고 보는 것이 정확합니다.

## 5. 장점

- **고전 마틴게일의 최악 단점 보완** — 물타기 상한(260주)과 그 이후의 기계적 손절(STOP_LOSS)로 "무한 물타기 → 계좌 전멸" 경로를 구조적으로 차단. 본전 탈출 규칙(+0.5%)으로 자금 고립 기간도 최소화.
- **감속형 피라미딩 설계** — 불타기 매수량은 20→20→10→5→2로 줄이고 요구 상승폭은 5→7→10→12%로 늘려, 고점 추격으로 평단가가 급등하는 위험을 체감시킴.
- **종목 선택의 정합성** — 대상이 지수 ETF(KODEX 200)라 개별주 대비 상장폐지·급락 리스크가 낮고 평균회귀 성향이 강해, "떨어지면 다시 오른다"는 물타기의 전제와 궁합이 좋음. ETF라 증권거래세 면제(코드에도 반영됨).
- **전략-코드 분리 아키텍처** — 매매 규칙이 INI 텍스트 파일로 외부화되어 코드 수정 없이 파라미터 튜닝 가능. 조건식은 로드 시 1회 컴파일되어 매 분 평가가 빠름.
- **운영 안정 장치** — 포트 기반 싱글턴(중복 실행 차단), 동일 봉 중복 처리 차단, 루프 예외 격리(로깅 후 계속), Fernet 키 암호화, 시작 시 계좌 잔고 동기화, 로그 + Markdown 일일 리포트 자동 기록.
- **부분 매도 인프라** — LIFO 랏 관리로 부분 청산도 지원 (현 전략은 전량 청산만 사용하지만 확장 가능).

## 6. 단점 및 리스크

- **손익비 역전 구조 (마틴게일 본질)** — 회당 이익 +0.5~1% vs 손절 시 최대 투입 대비 −6.9% (최초 진입금 대비 −83%). 이론상 손절 1회가 익절 약 7~14회를 상쇄. 백테스트 없이 승률·빈도를 검증하지 않으면 기대값이 양수인지 알 수 없음.
- **자금 효율 저하** — 최대 투입(12배) 기준으로 자금을 확보해야 하므로 평상시 자본 대부분이 유휴 상태. 수익률을 총 대기 자금 기준으로 환산하면 크게 희석됨.
- **추세 하락장 취약** — 약세장에서는 "진입 → 물타기 → 손절 → 즉시 재진입 → 다시 물타기"의 손실 사이클이 반복됨. 재진입 쿨다운, 일일 손실 한도, 추세 필터가 전혀 없음.
- **데이터 품질 의존** — Yahoo Finance의 KRX 분봉은 지연·누락이 잦아(수분~15분 이상 지연 사례 다수) 실시간 신호가 뒤늦게 발생할 수 있음. 모의투자 계좌(KIS/키움)에 이미 연결되어 있으면서 시세만 Yahoo를 쓰는 것은 정합성이 떨어짐.
- **분봉 종가 단위 판단** — 판단이 분당 1회이므로 분 내 급락(예: 1분에 −2%)은 다음 판정까지 대응 불가. 물타기 트리거와 손절 트리거를 한 봉에서 동시에 지나칠 수 있음.
- **체결 검증 부재** — 주문 "접수" 성공만으로 내부 포지션을 갱신. 지정가(현재 종가) 주문이 미체결·부분체결되면 내부 상태와 실제 계좌가 어긋나며, 이후 모든 트리거 가격이 왜곡됨.
- **지표 인프라 미활용** — EMA/MACD/RSI/ATR/VWAP를 매 분 계산하지만 이 전략의 조건식은 가격·수량만 사용. 계산 비용만 지불하고 추세 필터로는 쓰지 않음.

## 8. 개선 제안 요약 (우선순위)

1. **포지션 영속화 & 복원** (§7-1) — 랏 단위 상태(step, 매수가, 시각, highest_price)를 JSON으로 저장하고 재시작 시 복원. ✅ **2026-07-15 적용 완료**
2. **확정봉 사용** (§7-2) — timestamp 검증으로 완성된 봉만 신호 판정에 사용. ✅ **2026-07-15 적용 완료**
3. **체결 확인 + 예수금 검증** (§7-3) — 주문 후 체결 조회로 내부 상태를 확정하고, 매수 전 가용 현금 체크.
4. **재진입 제어 및 추세 필터** (§7-4) — STEP 1에 쿨다운/일일 한도/EMA 추세 조건을 추가해 하락장 반복 손실 차단.
5. **시세 소스 교체** — Yahoo 대신 이미 연결된 KIS/키움 API의 실시간 시세 사용 (지연·누락 제거, 주문 가격과 판정 가격의 정합성 확보).
6. **백테스트로 기대값 검증** — 손익비가 구조적으로 불리하므로(−6.9% vs +0.5~1%), 과거 KODEX 200 분봉으로 승률×손익비 기대값과 최대 낙폭(MDD), 물타기 진입 빈도를 반드시 정량 확인.
7. **중간 단계 리스크 한도** (§7-5) — 총자산 대비 평가손 한도, 갭하락 대응(저가 기준 트리거) 추가.
8. **운영 정리** — 주말/휴장일 체크, 하트비트 조건 수정, 수수료 파라미터화, BUY_STEP_5~10 중복 정리.

> **총평:** 고전 마틴게일에 "물타기 상한 + 기계적 손절 + 본전 탈출"이라는 안전판을 더해 **파산 경로를 구조적으로 막은 점**이 이 전략의 가장 큰 미덕입니다. 다만 실제 동작은 불타기 피라미딩보다는 **+1% 내외의 물타기 기반 스캘핑**에 가깝고, 손익비가 구조적으로 불리하므로 전략 자체의 기대값은 백테스트로 검증이 선행되어야 합니다. 코드 관점에서 가장 시급했던 **재시작 시 상태 복원 버그(§7-1)** 는 2026-07-15 랏 구조 영속화 방식으로 수정되었습니다.
