다음 순서로 git commit 및 push를 수행해주세요.

1. `git status`와 `git diff --stat`로 변경된 파일을 확인합니다.
2. `git log --oneline -5`로 최근 커밋 스타일을 참고합니다.
3. 변경된 파일 중 민감한 파일(.env, secret.key, *.pem 등)은 제외하고 관련 파일만 스테이징합니다.
4. 변경 내용을 분석하여 한국어로 간결한 커밋 메시지를 작성합니다.
   - 제목: 변경 핵심 내용 요약 (50자 이내)
   - 본문: 주요 변경 사항을 항목별로 정리
5. `git commit`으로 커밋한 후 `git push origin main`으로 푸시합니다.
6. 완료 후 커밋 해시와 푸시 결과를 알려줍니다.
